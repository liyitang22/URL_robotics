# Unsupervised RL for Robotics

A curated reading map tracing forward-backward representations and behavioral foundation models for robotics, from preliminaries to humanoid control and broader applications.

## Sections

- **Gallery**: short, muted previews from project pages.
- **Preliminaries**: forward-backward representations, adaptation, and related discussions.
- **Character Animation**: physics-based character behavior.
- **Whole-Body Control**: behavioral models for humanoid control.
- **Extensions**: interaction, perception, and multiple-robot projects.
- **Discussion**: work on zero-shot inference and latent-sequence optimization.

Open index.html locally to preview the site. The page is a standalone HTML file and needs no build step.
